# Политика безопасности / Security Policy

Если вы нашли уязвимость (например, путь к выполнению чужого кода через параметры скрипта или подмену скачиваемых компонентов) - пожалуйста, не публикуйте детали в открытом Issue. Сообщите приватно через [GitHub Security Advisories](https://github.com/bivlked/YTDownload/security/advisories/new).

If you found a vulnerability, please do not disclose it in a public issue - report it privately via [GitHub Security Advisories](https://github.com/bivlked/YTDownload/security/advisories/new).

Поддерживается только последний релиз: перед сообщением проверьте проблему на [актуальной версии](https://github.com/bivlked/YTDownload/releases/latest).
